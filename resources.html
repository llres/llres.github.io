📁 FILE LIBRARY

想找什么，进文件夹看。

这里不再按固定卡片展示资源。你可以直接按文件夹整理软件、资料、压缩包、图片、视频和其他杂七杂八的东西，网站会自动把目录变成在线文件库。

整理方式很简单：在仓库的 resources/ 文件夹里自己建目录、放文件即可。比如 resources/软件/Windows/、resources/学习资料/高等数学/。刷新本站后会自动显示。大文件建议以后接入对象存储，不要长期堆进 Git 仓库。
